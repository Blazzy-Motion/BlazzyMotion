# Demo fonts

Unmodified variable WOFF2 Latin and Latin Extended subsets from `@fontsource-variable/outfit@5.3.0` and `@fontsource-variable/jetbrains-mono@5.3.0`, downloaded from the npm registry. Both fonts use the SIL Open Font License 1.1; full copyright notices and licenses are included alongside the font files.

These assets serve the Demo startup screen and code examples without third-party font requests. The existing font family names are retained, and `font-display: swap` keeps content visible during loading. These are Demo assets, not library package assets.
